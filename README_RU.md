# Luma TV 7.0 — luDOS 1.0 • Glass Ultra Update

## Что нового

- Главный экран больше не пустой: большая **живописная карточка luNature** с текущим пейзажем и переходом к выбору обоев, **стеклянная панель времени/даты/режима**, ряд программ, «Недавно открывали», **мини-галерея из пяти пейзажей** и быстрые действия.
- Раздел «Избранное» и старый слоган «Твой экран. Твои правила.» **не возвращались**.
- В режиме **ULTRA** используется новое оформление `LuGlassDrawable.kt`: реальное **статическое размытие копии выбранных обоев внутри карточек**, многослойная прозрачность, градиентные блики, двойной световой контур, мягкий цветовой ореол при выделении пультом.
- **BALANCED** и **LITE** сохранены. Переключение в «Настройки luDOS»; ULTRA можно включать на любом устройстве, если хватает производительности.
- Размытие кешируется в виде 320×180 bitmap (около 230 КБ) и создаётся только при необходимости. Оно не работает постоянно и не захватывает содержимое чужих приложений.
- Кнопка выбора файла обоев по-прежнему отсутствует. Остались пять штатных пейзажей и автосмена.
- Приложение: Kotlin + нативный Android SDK, `applicationId=com.lumatv.launcher`, `versionName=7.0`, `versionCode=13` (увеличен ради обновления).
- luDOS по-прежнему **1.0**. В интерфейсе нет бренда или характеристик конкретного телевизора.

## Что важно про эффект Liquid Glass

Оформление **вдохновлено** прозрачными материалами современных ТВ-интерфейсов. **Это не точная реализация Apple iOS 26**: в Android 5–11 нет доступного для лаунчера штатного системного `RenderEffect` (появился с Android 12 / API 31), а оригинальное оптическое преломление Apple не перенесено. Нативная реализация создаёт **эффект стекла на фоне обоев**, а не системный live blur-behind.

## Совместимость

Для Android TV / Google TV и совместимых Android-приставок начиная с Android 5 (API 21). Android APK не запускаются напрямую на webOS/Tizen/Roku/tvOS. Возможность замены домашнего экрана зависит от прошивки производителя.

## Как установить обновление через GitHub

1. Скачайте и распакуйте архив `LumaTV_7_0_GlassUltra_APP.zip`.
2. В репозитории обновите папку `app/` целиком, включая **НОВЫЙ ФАЙЛ** `app/src/main/java/com/lumatv/launcher/LuGlassDrawable.kt`.
3. Сохраните пути файлов; нажмите `Commit changes`.
4. Запустите `Actions → Build Luma TV APK` (или дождитесь запуска от push).
5. После зелёной галочки скачайте APK из `Artifacts` и проверьте установку. Если раньше устанавливался APK с иной подписью, может потребоваться переустановка с потерей настроек.
6. На устройстве проверьте: отображение карточек, отсутствие обрезки рамок при масштабировании, переключение обоев, работу пульта, переходы в программы, режимы LITE/BALANCED/ULTRA.

**Не удаляйте заводской системный лаунчер.** Этот архив — исходники, не собранный APK. Успешная компиляция и работа на реальных телевизорах ещё требуют проверки. Целевой размер APK — не более 10 МиБ, не гарантия.
