# Luma TV 7.0 • luDOS 1.0 • Glass Ultra Update

- `versionCode`: 12 → 13; `versionName` остаётся 7.0.
- Новый главный экран: luNature hero, часы/дата/режим, приложения, недавние, пять превью обоев, быстрый доступ.
- luGlass ULTRA: `LuGlassDrawable` с кешированным wallpaper-only frosting, краевыми бликами, двойными контурами и цветным focus glow.
- Поддержка Android API 21+: ни RenderEffect, ни RenderScript, ни сторонние библиотеки не требуются.
- Сохранены три профиля LITE / BALANCED / ULTRA, luDOS 1.0, навигация пультом и пользовательские настройки.
- Не возвращены «Избранное», старый слоган и загрузка пользовательских обоев.
- Не заявлена работа на всех ТВ ОС или точная копия движка Apple.
